
# NETFLIX – Elokuvasovellus

## Projektin tarkoitus

Projektin tarkoituksena on toteuttaa elokuvasovellus, jossa käyttäjä voi selata elokuvia, tutustua niiden tietoihin ja tallentaa omia suosikkielokuviaan.

## Ominaisuudet

- Elokuvien näyttäminen
- Elokuvien hakeminen
- Elokuvien suodattaminen genren mukaan
- Uusien elokuvien lisääminen
- Elokuvien tietojen muokkaaminen
- Elokuvien poistaminen
- Elokuvien lisääminen suosikkeihin
- Suosikkielokuvien näyttäminen
- Responsiivinen käyttöliittymä
- Vaalea ja tumma teema

## Käytetyt teknologiat

- HTML5
- CSS3
- JavaScript
- JSON Server
- REST API
- Fetch API
- Git ja GitHub

## Projektin käynnistäminen

1. Avaa projektikansio VS Codessa.
2. Asenna JSON Server tarvittaessa:

   npm install -g json-server

3. Käynnistä JSON Server projektikansiossa:

   json-server --watch db.json --port 3000

4. Käynnistä HTML-sovellus esimerkiksi VS Coden Live Server -laajennuksella.
5. Avaa sovellus selaimessa.

## Tietokanta

Sovelluksen elokuvat tallennetaan db.json-tiedostoon JSON Serverin avulla.
